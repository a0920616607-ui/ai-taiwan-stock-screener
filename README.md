# AI 台灣個股智慧選股 V6.9｜手機精簡列表修正版

## 這次真正修正
V6.8 使用寬表格，手機只能看到前幾欄，因此看起來像沒有改到。

V6.9 已完全取消橫向表格，改成固定六欄手機列表：
- 代號／名稱
- 收盤
- 燈號
- AI總分
- 法人／主力
- 量能

所有欄位會直接出現在同一個手機畫面，不必左右滑動。

## 點擊細項
點擊股票代號或名稱，才會開啟完整細項：
- 技術、法人、主力
- 三大法人、外資、投信、自營商
- KD、RSI、MACD、量比
- 評分原因
- 加入自選股

## 燈號
- 紅色上箭頭：買入
- 綠色下箭頭：賣出
- 灰色減號：中性
