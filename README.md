# AI 台灣個股智慧選股 V8.2｜EMA100 圖形燈號版

## 使用方式
首頁維持原本列表。點擊股票代號／名稱後，個股內頁新增第四個頁籤：

`EMA100訊號`

## 圖形內容
- 個股最近 90 根價格線
- EMA100 線
- 最新股價位置點
- 最新 EMA100 位置點
- 顯示目前位於多方區或空方區
- 顯示股價距離 EMA100 百分比
- 顯示 EMA100 上彎或走平／下彎

## 燈號強度
下方顯示五格偏多與偏空強度：

- 股價位於 EMA100 上／下方
- EMA100 是否上彎
- MACD 是否位於訊號線上方
- MACD 柱體正負
- 量價是否同步放大

## 提醒
這是條件累積訊號，不代表必然反轉，仍需搭配法人、主力、量能及其他技術條件確認。
