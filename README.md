本版不是只改版本號，而是依照指定的右側參考畫面完整重做介面。

- 深色科技背景與專業卡片層次
- 六個主要功能固定 3 欄 × 2 列
- 每個功能按鈕加入圖示、同寬、同高、同間距
- 手機與較寬畫面均保持整齊
- 上市／上櫃類股改為三欄專業卡片
- 顯示資料時間與股票檔數
- 新增類股成分股漲跌排行
- 可切換漲幅、跌幅、平盤排行
- 點擊類股卡片後載入該類股成分股
- 點擊股票列可直接進行 AI 分析
- AI 排行榜改為專業表格版面
