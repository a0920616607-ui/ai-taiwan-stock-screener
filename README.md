# AI 台灣個股智慧選股 V13

## V13 更新（本次）
- **首頁改為簡單畫面**：App 開啟直接顯示「上市類股漲跌」總覽＋成分股排行榜，不需先設定篩選條件即可看盤（可再切到「AI 選股」做完整篩選）。
- **成交量門檻**：全市場掃描與類股排行都會自動剔除成交量 < 1000 張的個股，避免流動性不足的雜訊股。
- **類股成分股排行改為真實 AI 分析**：先前「AI總分／法人／主力」為固定 0，現在會即時對成分股跑完整技術＋法人＋主力分析。
- **Yahoo 歷史行情快取（15 分鐘）**：大幅減少全市場掃描時對 Yahoo 的重複請求，掃描更快、更不易被限流。
- **法人分數改為金額分級**：買賣超依張數規模分「大額／中額／小額」給分，不再是買 1 張跟買 1 萬張同分。
- **CSV 匯出**：掃描結果、排行榜、自選股分類皆可一鍵匯出 CSV。
- **簡易速率限制**：內建輕量限流保護 `/api/scan`、`/api/stock`，避免短時間被大量觸發。
- **PWA 圖示**：補上 192×192／512×512 icon，加到手機主畫面會有圖示。

## 核心更新

### 1. AI 智慧模式（預設）
- 最低 AI 分數仍是必要條件。
- EMA100 乖離、主升啟動、AI 起漲、技術條件、法人條件改為「排名加分」。
- 高分股票不會因單一次要條件未成立而直接消失。
- 顯示「智慧排名分」與加分值。

### 2. 嚴格篩選模式
- 保留 V11.1 原本的 AND／OR 與硬條件過濾。
- 適合只尋找完全符合特定進場條件的股票。

### 3. 全市場一鍵掃描
- 「智慧選股掃描」會自動分批掃描整個選定市場，不再只分析第一頁 20 檔。
- 預設每批 60 檔並顯示批次進度。
- 掃描中斷時保留已完成批次及上次排行榜。

### 4. 排名邏輯
- 先依原始 AI 分數建立基本品質。
- 再依使用者偏好條件加分排序。
- 自選股單股分析與 AI 搜尋仍共用同一個基礎 AI 分數。
