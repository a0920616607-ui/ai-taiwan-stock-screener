# AI 台灣個股智慧選股 V11.0－主升啟動版

## V11 核心更新
- 新增「🚀 主升啟動」一鍵篩選。
- 自動內含：布林帶寬 ≤ 8%、量比 ≥ 1.2、DIF 位於 MACD 零軸之上。
- 可加選 EMA100 多頭過濾：股價站上 EMA100 且 EMA100 上彎。
- 顯示昨日布林帶寬、收縮／擴張與連續收縮天數。
- 符合條件的股票顯示「🚀主升啟動」標籤。

- 上市、上櫃與混合搜尋結果統一依 AI 分數由高至低排列。
- 已掃描批次合併後重新全域排序，避免第三頁分數高於第一頁。
- 排序選項預設並固定為「AI 分數高→低」，切換其他排序仍可使用。
