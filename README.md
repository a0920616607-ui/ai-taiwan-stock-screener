# AI 台灣個股智慧選股 V9.4｜連線錯誤修正版

## 修正內容
- Render 回傳 502、503、HTML 錯誤頁或逾時時，自動重試 3 次。
- 重試間隔為約 1.8 秒、3.5 秒、7 秒。
- 同步失敗但手機已有股票名單時，沿用手機快取繼續掃描。
- 掃描失敗時保留上次結果，不再清空為 0。
- 移除智慧掃描的阻斷式錯誤彈窗，改在畫面內顯示狀態。
- `/api/universe` 無論成功或失敗都回傳 JSON。
- 後端資料來源失敗時，優先使用記憶體或 Render 暫存快取。

## V9.4 新增功能
- 預設僅顯示 AI 70 分以上，可切換 80／90／全部。
- EMA100 正乖離上限可選 3%／5%／8%／10%／不限。
- AI 起漲條件：站上 EMA100、EMA100 上彎、MACD 位於 0 軸上且黃金交叉、EMA100 正乖離 5% 內。
- 布林通道 Bollinger Bands（20,2）：上軌、中軌、下軌、開口／收斂與價格位置。
- 個股圖表同時顯示股價、EMA100 與布林通道。
- AI 權重調整為技術 55%、法人 25%、主力 20%。
