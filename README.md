# AI 台灣個股智慧選股 V10

## V10 重點更新
- 技術條件支援「任一符合」或「全部符合」，可自由勾選，不再強迫所有條件同時成立。
- 新增布林位階：下軌 -10、中軌 0、上軌 +10，突破時延伸至 ±12。
- 新增月斜：以布林中軌（20MA）近 5 根標準化斜率判斷偏多、偏空、強多、強空。
- 新增布林位階、月斜、布林開口、外資與投信條件篩選。
- 法人資料在週末、假日或官方端點暫時空白時，沿用最近一次成功交易日資料；缺資料不再冒充 0 股。
- 法人狀態列顯示資料日期與是否採用最近交易日備援。
- 成交量與量比沿用 Yahoo 最新交易日行情，並在資料中保留價格／成交量日期。
