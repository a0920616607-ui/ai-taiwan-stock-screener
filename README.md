## 燈號規則
- 紅色上箭頭：買入
- 綠色下箭頭：賣出
- 中性：不顯示燈圈，只顯示中性文字
- 燈號旁顯示 AI 總分

## 法人、外資、主力與量能
每檔股票顯示：
- 三大法人淨買賣超
- 外資淨買賣超
- 主力代理分數
- 量比

提示規則：
- 法人或外資買超＋主力偏多＋量比放大：買入量能放大
- 法人及外資賣超＋主力偏空＋量比放大：賣出量能放大
- 只有量比放大：量能放大
- 未放量：量能平穩

主力仍為代理模型，不是券商分點真實主力張數。
