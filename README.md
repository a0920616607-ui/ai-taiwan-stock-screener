# AI 台灣個股智慧選股 V6.3｜三合一評分穩定版

## 三合一總分
AI 總分 = 技術分析 50% + 法人籌碼 30% + 主力動能 20%

每檔股票顯示：
- AI 總分
- 技術分數
- 法人分數
- 主力分數
- 收盤、KD、RSI、MACD、量比
- 評級：強勢候選／積極觀察／轉強觀察／等待確認／暫不列入

## 分數區間
- 90～100：強勢候選
- 80～89：積極觀察
- 70～79：轉強觀察
- 60～69：等待確認
- 60 以下：暫不列入

## 同步流程修正
- 股票名單會保存在手機瀏覽器。
- 重新整理後仍可開始掃描，不必每次重新同步。
- 首頁顯示上次同步時間。

## 主力說明
主力沒有官方統一欄位。本版仍以法人方向、量比、價格動能與 MACD 建立主力代理分數，
不是券商分點真實主力集中度。
