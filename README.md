# AI 台灣個股智慧選股 V12

## 核心更新

### 1. AI 智慧模式（預設）
- 最低 AI 分數仍是必要條件。
- EMA100 乖離、主升啟動、AI 起漲、技術條件、法人條件改為「排名加分」。
- 高分股票不會因單一次要條件未成立而直接消失。
- 顯示「智慧排名分」與加分值。

### 2. 嚴格篩選模式
- 保留 V11.1 原本的 AND／OR 與硬條件過濾。
- 適合只尋找完全符合特定進場條件的股票。

### 3. 全市場一鍵掃描
- 「智慧選股掃描」會自動分批掃描整個選定市場，不再只分析第一頁 20 檔。
- 預設每批 60 檔並顯示批次進度。
- 掃描中斷時保留已完成批次及上次排行榜。

### 4. 排名邏輯
- 先依原始 AI 分數建立基本品質。
- 再依使用者偏好條件加分排序。
- 自選股單股分析與 AI 搜尋仍共用同一個基礎 AI 分數。
