# AI 台灣個股智慧選股 V8.5｜專業介面與排行榜歷史版

## 介面重做
- 上方六個主要功能固定排成 3 欄 × 2 列。
- 六個按鈕同寬、同高、同間距，手機版不再歪斜。
- 加入簡潔線性圖示、藍紫漸層選取狀態。
- 類股卡片與排行榜重新排版，更接近專業股票軟體。

## AI 排行榜歷史
- AI 掃描、單股分析、自選股分析都會加入排行榜。
- 每天自動建立一份排行榜快照。
- 最多保留最近 30 天。
- 可切換日期查看過去排行榜。
- 顯示 AI 分數相對前一日的變化。
- 新進榜顯示 NEW。
- 分數連續三日轉強顯示 HOT。
- 同一股票重新分析會更新，不重複堆疊。

## 儲存方式
排行榜歷史目前儲存在該手機／瀏覽器的 localStorage。
清除瀏覽器資料、換手機或換瀏覽器後不會同步。
