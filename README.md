# AI 台灣個股智慧選股 V9.1｜上櫃穩定修正版

## 修正內容
1. 上櫃股票來源改為多來源候補：
   - TPEx 上櫃股票收盤行情 OpenAPI
   - TPEx 每日收盤行情 OpenAPI
   - TPEx 新版盤後行情
   - TPEx 舊版盤後行情
2. 每個來源最多重試 3 次。
3. 加入記憶體及 Render 暫存磁碟快取。
4. 伺服器暫時抓不到上櫃名單時，保留手機瀏覽器先前成功同步的上櫃名單。
5. AI 掃描會把手機端本頁股票批次送到伺服器分析，不再因伺服器名單暫時為 0 而無法掃描。
6. 同步時若新資料只有上市，不會覆蓋掉手機原本保存的上櫃 808 檔資料。

## 操作
部署完成後先按一次「同步股票名單」，再選擇上櫃開始掃描。
