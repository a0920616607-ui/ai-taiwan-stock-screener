# AI 台灣個股智慧選股 V9 Ultimate 專業版

這一版針對 V9 外觀未明顯改變的問題，直接重建手機首頁視覺。

## 主要改動
- 六個主要功能固定為 3 欄 × 2 列。
- 使用真正的 SVG 線性圖示，不再使用容易被手機隱藏或顯示不同的文字符號。
- 即使手機畫面寬度低於 390px，圖示仍然保留。
- 按鈕縮為專業工具列比例，不再是大型方塊。
- AI 選股首頁加入專業標題列、即時分析標籤與重新設計的操作按鈕。
- 分析週期與篩選區重新排列。
- 保留 V9 原有的 AI 選股、排行榜歷史、單股分析、自選股、類股與成分股排行功能。

## 部署
覆蓋 GitHub 後等待 Render 完成部署。CSS/JS 快取版本為 91。
若手機仍顯示舊畫面，請關閉原分頁後重新開啟網址，或清除該網站快取。
